# Vision

`refrain` is a durable workflow engine: a system designed to execute multi-step processes in a simple, efficient, and reliable way.

More than a product goal, this project is a laboratory for exploring and learning concepts such as long-running computation, process failure, workers, machines, and networks.

The primary objective behind building this system is to learn backend engineering, distributed systems, and software architecture from first principles.

Although the project is inspired by Temporal, it is not intended to copy or reimplement Temporal's feature set. Its central purpose is learning and developing a deeper understanding of the concepts behind this kind of system. The expectation is to learn directly from the problems that emerge throughout the process.
