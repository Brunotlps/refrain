# Methodology

The learning methodology for `refrain` follows this sequence:

```text
QUESTION
   ↓
RESEARCH
   ↓
HYPOTHESIS
   ↓
DESIGN
   ↓
IMPLEMENT
   ↓
BREAK
   ↓
MEASURE
   ↓
REFLECT
```

## AI Agent Contract

- `Tutor` -> explains and asks questions
- `Reviewer` -> critiques my implementation
- `Pair` -> helps with specific parts
- `Accelerator` -> implements peripheral work

## Milestone Declaration

Each milestone should explicitly declare:

- `Learning Target`
- `AI Mode`
- `Research Question`
- `Success Criteria`
