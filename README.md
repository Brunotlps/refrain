# Refrain

`refrain` is a learning-driven exploration of durable workflow systems.

The project is intended as a practical laboratory for studying backend engineering, distributed systems, and software architecture from first principles. It is inspired by systems such as Temporal, but it is not meant to reproduce them feature by feature. The goal is to understand the concepts behind long-running computation, failure handling, workers, machines, and networks by building and learning through the process.
